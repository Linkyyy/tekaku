# Windows 0.12.1 大纲跳转

- 在阅读模式中，点击右侧大纲标题即可将对应章节滚动到正文可见区域。
- 编辑模式也可点击标题定位，光标移到标题开头。同名标题按文档顺序分别定位。
- 在源码视图点击标题会返回正文。即使刚修改源码，跳转也使用更新后的标题位置。

更新前请保存文档并退出手书。完整解压 ZIP，保留 `Tekaku.exe` 和 `WebView2Loader.dll` 在同一目录。支持 Windows 10/11 x64，需要系统 WebView2。
