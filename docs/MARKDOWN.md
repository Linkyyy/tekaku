# Markdown 编辑指南

手书支持同一页面内的实时编辑、Markdown 快捷输入、`/` 内容块菜单、右键菜单插入和源码编辑。默认左侧栏收起；编辑区右键或 Shift+F10 打开菜单，“段落样式”和“插入内容”提供全部常用内容类型。

| 内容 | Markdown 输入示例 | 其他入口 |
| --- | --- | --- |
| 一至六级标题 | `# ` 至 `###### ` | 右键“段落样式”、`/` 菜单、Ctrl+Alt+1…6 |
| 正文 | 直接输入 | 右键“段落样式” |
| 粗体 / 斜体 | `**文字**` / `*文字*` | Ctrl+B / Ctrl+I |
| 删除线 | `~~文字~~` | 可选格式工具栏 |
| 行内代码 | 用单个反引号包围代码 | Ctrl+E、右键“插入内容 → 行内代码” |
| 代码块 | 段落开头输入三个反引号、语言名，再按空格 | Ctrl+Alt+C、右键“插入内容 → 代码块”、`/` 菜单 |
| 无序 / 有序列表 | `- ` / `1. ` | 右键菜单、`/` 菜单 |
| 待办 | `[] ` 或 `[ ] `；源码使用 `- [ ] 任务` | 右键菜单、`/` 菜单 |
| 引用 | `> ` | 右键菜单、`/` 菜单 |
| 分割线 | 源码中一行 `---` | 右键菜单、`/` 菜单 |
| 链接 | `[名称](https://example.com)` | Ctrl+K |
| 图片 | `![说明](图片路径)` | 拖入 / 粘贴 / Ctrl+Shift+I |
| GFM 表格 | 竖线与表头分隔行 | 右键菜单、`/` 菜单 |

## 快捷输入指南

左下角悬浮按钮展开侧栏 → 输入指南 → Markdown 快捷输入。指南并排展示输入示例与显示效果，区分行首内容块、文字样式和源码示例。标题与页签始终保留，内容单独滚动，Esc 关闭。源码/预览切换保持同一编辑区域，分别记住滚动位置。

## 代码编辑

- 支持纯文本，以及 JavaScript、TypeScript、Python、C、C++、C#、Java、Go、Rust、PHP、Ruby、Swift、Kotlin、Dart、JSON、YAML、INI/TOML、HTML/XML、CSS、Shell/Bash、PowerShell、SQL、Markdown、Diff、Dockerfile。
- 常见语言别名如 js、ts、py、yml、c++、c# 可以导入并高亮。未知语言仍保留代码及语言名；没有对应语法高亮时显示“无高亮”。
- 点击代码块后出现语言选择、复制代码和自动换行按钮。自动换行属于显示选项，不改写代码内容。
- Tab 插入两个空格；多行选区对整行缩进，Shift+Tab 取消缩进。选择下一行的行首作为结束位置时，该行不参与缩进。
- 在代码块末尾连续按三次 Enter 回到正文；Ctrl+Alt+C 也可切换代码块。
- 代码里包含三个反引号时，保存使用更长的围栏，避免代码被截断。保存后重开也会保留代码文本。
- 所有代码均作文本编辑与高亮显示，编辑器不执行代码。

## 源码与列表

右下角 </> 图标或 Ctrl+Shift+M 在同一区域切换源码。右侧为独立大纲栏，点击标题定位，再次点击内容区大纲悬浮按钮可收起，并记住显示状态。
文档滚动条在工作区最右侧，大纲出现时位于其右侧；大纲自身可滚动，隐藏滚动条。源码支持 Tab / Shift+Tab 缩进与原生撤销；保存直接使用源码文本。列表中 Tab / Shift+Tab 增减层级。

目前不提供公式排版、Mermaid 渲染、脚注和 YAML front matter 专用编辑。支持常用 Markdown 和 GFM 内容，不声称覆盖所有扩展；复杂文档建议先另存为，核对后再覆盖原文件。

右键菜单支持撤销/重做、纯文本复制/剪切/粘贴、段落样式和内容插入。键盘可用 Shift+F10 打开、上下选择、左右展开/返回、Enter 执行、Esc 关闭。源码模式的插入操作写入 Markdown 文本，并保留撤销能力。Windows 桌面版使用原生纯文本剪贴板；粘贴图片仍使用 Ctrl+V。
