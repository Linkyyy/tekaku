# Windows 0.10.0 发布检查

日期：2026-10-27（日本时间）。本次只更新 PC，Android 保持 0.1.0。

## 本版变化

- 仅文档内容保留可见滚动条，大纲、侧栏、指南、设置和菜单隐藏滚动条但仍能滚动。
- 文档滚动条位于工作区最右侧，大纲出现时在大纲右侧；控制预览与源码滚动。
- 窗口保留真实原生缩放边缘；客户端边缘与顶栏改用系统缩放/移动消息及真实鼠标坐标。最小尺寸按 DPI 调整并限制在显示器工作区内，全屏不受最小跟踪尺寸撑大。
- 全屏、最大化和普通窗口均保留内容区悬浮按钮；侧栏展开时按钮随内容区移动。
- 侧栏和大纲采用宽度滑入、滑出动画，默认开启，可在设置中关闭。
- 所有应用内操作图标统一为蓝色 SVG，程序和任务栏图标也改为蓝色。
- 大纲取消关闭按钮，再次点击大纲悬浮按钮即可收起。

Android 保持 0.1.0。本次只更新 PC。


## 实际检查

- 55 项桌面界面 / 模拟原生桥接回归通过；最终对工作区和嵌入页面另做 7 项定向复查，包括源码字号改变后滚动条范围更新。
- 检查了辅助区域滚动条隐藏后仍可滚动、文档滚动条位于大纲右侧并驱动预览/源码、全屏/最大化/展开侧栏时悬浮按钮的可见性和命中、实际鼠标触发八向缩放协议、四种皮肤下统一的蓝色矢量图标。
- 逐帧采样确认侧栏和大纲存在中间宽度，实际动画在运行；另附 Chromium 实际录屏生成的 GIF（应用源码 docs/panels-motion.gif），没有修改动画速度。
- 12 项 Go 测试通过，新增系统缩放方向、负屏幕坐标、DPI 边缘和显示器/全屏最小跟踪尺寸检查。
- 两次最终 EXE 构建逐字节一致；从 PE 提取并核对 0.10.0.0 版本和 9 种尺寸的蓝色图标。
- ClamAV 1.5.4、病毒库 28164（2026-10-25）扫描最终 EXE、SDK DLL、ZIP，3 个输入均 OK，Infected files: 0，无文件访问错误。容器断网、只读挂载；镜像固定摘要 sha256:bda39705e291105049c3936e2803ac90b955172af8030f94f05dce1252df6c6d。扫描原始时间由引擎以 UTC 记录。
- 官网 1440 / 768 / 390 像素宽度、四种皮肤图片、新版链接与校验值、未改变的 Android 链接均通过检查。

## 验证范围

当前环境为 Linux，完成了 Windows 交叉编译。浏览器里的真实鼠标拖动验证的是客户端命中与桥接协议，Go 测试验证消息方向、坐标和尺寸计算；不能代替 Windows 上的真实窗口拖拽、原生边框绘制、DPI/多显示器和任务栏实机测试。这些原生效果仍需 Windows 实机复核。

EXE 尚未进行 Authenticode 签名，“下载不常见”或未知发布者提示可能继续出现。单一引擎未检出不是绝对安全保证；没有 Defender 或多引擎检测结论。ZIP 自身的哈希与最终扫描输出单独提供，避免放入 ZIP 造成循环。

官网源仓库和 Vercel 绑定仓库同步；当前环境不能读取 Vercel 部署状态。
