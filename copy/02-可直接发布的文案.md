我做了一个叫「手书 Tekaku」的小工具，想让写 Markdown 这件事更直接一点。

写课程笔记时，标题、待办和引用会在输入时呈现，不用一直盯着两块区域。遇到需要记下来的代码，也能放进同一份文档。

它目前有这些基础功能：

• 在同一区域输入与阅读 Markdown
• 多文件 Tab，学习记录和项目笔记切换着写

• 本地文件、无需登录，提供 Windows 与 Android 版

默认是灰蓝主题，也可以换成纯白、纸笺等皮肤。Windows ZIP 下载包约 1.9 MB——这里说的是下载体积，运行内存还需要实机测量，且需要系统 WebView2。

## V2EX / 开发者社区：作者分享版

**标题：做了个轻量的本地 Markdown 编辑器，想听听学生和开发者的反馈**

大家好，我做了一个 Windows / Android Markdown 编辑器，叫手书 Tekaku。

初衷是让本地 .md 文件的打开和编辑更直接：在同一页边写边呈现，不做左右分栏；几份文档用 Tab 切换，配上代码高亮、图片、表格、大纲与查找替换。

Windows 版用 Go + 系统 WebView2，没有随包附带完整浏览器，当前便携 ZIP 约 1.9 MB。它仍依赖 WebView2，不能把下载体积当作内存表现。目前没有可靠的 Windows 内存实测。

源码公开：
https://github.com/Linkyyy/tekaku

这次更想收集具体场景：课程笔记、项目 README、代码片段、临时文档，你会在哪一步觉得现有编辑器过重或操作繁琐？

也先说明现阶段的不足：

## 掘金：文章标题与导语

**推荐标题：用 Go + WebView2 做一个轻量 Markdown 编辑器：手书 Tekaku 的取舍**

**导语：**

写一个 Markdown 编辑器时，我想先解决一个很小的场景：打开一份本地文档，直接写，切换几份文件时不要打断思路。

手书 Tekaku 的 Windows 版使用 Go 承载系统 WebView2，编辑区基于 Tiptap，多标签共用一个编辑器视图，分别保留文档状态。当前 ZIP 约 1.9 MB，这主要反映分发方式，不代表已取得某个内存或性能成绩。

这篇文章准备谈四个实际取舍：系统 WebView2 的依赖、Markdown 与富文本往返、单编辑器多标签的状态保存、未保存修改与文件路径的保护。源码与已知问题一起公开，希望得到更多真实使用反馈。

**文章结构：** 为什么做 → 真实操作演示 → 架构与体积来源 → 多 Tab 状态 → 文件保存保护 → 目前限制与测试范围 → 源码与反馈。不要为文章补造启动时间、内存对比或对竞品的性能结论。

## GitHub / 英文简短介绍

**Tekaku — a lightweight, local Markdown editor.**

Write study notes and technical documents in one calm workspace. Tekaku combines in-place Markdown editing, tabs, code highlighting, images, tables, and local files. Available for Windows and Android.

The Windows ZIP is about 1.9 MB and uses the system WebView2 runtime. Download size is not a memory benchmark. Desktop and mobile use their own local files; automatic sync is not included.

This is a public test build. Please read the supported features, dependencies, verification limits, and unresolved Windows download-security report before trying it.
