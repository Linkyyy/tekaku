# 卖点事实表与使用边界

这张表供后续改稿时查用。宣传图不代替版本说明、平台审核或安全检查。

| 可以表述 | 所指范围 | 避免写成 |
|---|---|---|
| Windows ZIP 下载包约 1.9 MB | 0.11.1 的 ZIP 为 1,909,492 bytes，另需系统 WebView2 | 内存只占 1.9 MB、零依赖、无需系统运行时 |
| Android APK 约 235 KB | 0.1.0 的分发 APK；运行依赖系统 WebView | 运行只占 235 KB、所有 Android 都兼容 |
| 同一页边写边呈现 | 富文本 Markdown 编辑视图，另有源码切换 | 支持所有 Markdown 扩展、完全无损往返 |
| Windows 多文件 Tab | 桌面版内可打开、切换多份文档，保存目标分别处理 | Android 已具备同样标签功能、多人实时编辑 |
| 图片、表格、代码高亮 | 常用内容块与代码语言选项 | 已支持公式、Mermaid、任意插件 |
| 本地文件、无需登录 | 文档由用户选位置保存；草稿在应用数据目录 | 自动云备份、绝不会产生网络访问 |
| 可离线编辑本地内容 | 系统运行时已具备；网络图片与主动网页链接仍需联网 | 任何功能在任何情况下都完全不联网 |
| Windows 与 Android 版 | 两端分别使用各自本地文件，手机版功能范围不同 | 跨端自动同步、已提供 iOS/macOS/Linux |
| 源码公开 | 当前项目代码可在 GitHub 查看 | 已经过第三方安全认证或平台审核 |

尚无可靠的 Windows 内存与启动耗时实测，不使用“秒开”“几乎不占内存”“全网最轻”等绝对或比较结论。
